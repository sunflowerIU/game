# Neon Dice — Section 5: player interface

Section 5 adds the player-facing Neon Dice journey while leaving the catalog
game disabled for launch control. Music and game-specific sound design remain
reserved for Section 6.

The interface includes:

- a distinct lobby tile and first-roll entry panel;
- Under 7, Exactly 7, and Over 7 choices with their ranges and multipliers;
- configured wager denominations from 0.50 through the 30-coin ceiling;
- an animated two-dice table that always settles on the authoritative server
  result;
- clear total, win/loss, reward, wager, and selected-outcome feedback;
- repeat rolls without returning to the lobby;
- retry-safe idempotency keys retained across uncertain network failures;
- responsive portrait, tablet, desktop, short-landscape, and small-phone
  layouts; and
- keyboard focus, live result announcements, and reduced-motion support.

No dice value, total, result, or reward is generated by the browser. The client
only animates the result returned by the atomic Neon Dice settlement endpoint.
